**Last updated:** August 9, 2026

This Privacy Policy and KVKK Information Notice explains how Martinari ("Martinari", "we", "us", or "our") processes personal data when you visit or use Martinari.

Martinari is designed as a no-account, peer-to-peer file transfer service. We intentionally aim to minimize the amount of personal data collected.

## 2. What Martinari May Process

Depending on how you use the service and how the server is configured, Martinari may process limited technical information, including:

* IP address.
* Date and time of connection.
* WebSocket connection information.
* Room identifier or room code.
* Peer/session identifiers generated for the connection.
* Browser or device-related technical information contained in standard server requests.
* Technical error or security logs.

Martinari does **not** require:

* An account.
* Your name.
* Your email address.
* A password.
* A user profile.

## 3. File Contents

Martinari's architecture is designed so that transferred files travel directly between participating browsers using WebRTC Data Channels.

Martinari's signaling server is not intended to receive, store, or inspect the contents of transferred files.

However, WebRTC connections may involve technical networking information necessary to establish a peer-to-peer connection.

You should therefore not assume that use of Martinari makes your network identity completely anonymous.

## 4. Purposes of Processing

Technical personal data may be processed for purposes including:

* Establishing WebRTC connections.
* Operating room and signaling functionality.
* Maintaining the security and reliability of the service.
* Preventing abuse and malicious activity.
* Diagnosing technical problems.
* Detecting and responding to security incidents.
* Complying with legal obligations.
* Responding to lawful requests from competent authorities.

Martinari will not use personal data for unrelated purposes merely because it has been technically available to us.
